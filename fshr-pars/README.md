# FSHr Chess Rank Parser

Инструмент для автоматического сбора информации о выполнении разрядов шахматистами на сайте [ratings.ruchess.ru](https://ratings.ruchess.ru).

Программа принимает ID игрока, обходит все его турниры и извлекает отметку о выполнении разряда (колонка «Нор» в таблице результатов). Результат выводится в консоль и сохраняется в CSV-файл.

## 🎯 Мотивация

Создано для тренеров и родителей юных шахматистов, чтобы быстро отслеживать прогресс и выполнение спортивных разрядов. Может использоваться как основа для бота или системы уведомлений.

## ⚙️ Технологии

- **Python 3.9+**
- **Playwright** (headless Chromium) — для загрузки динамических страниц
- **BeautifulSoup4** — парсинг HTML

## 🔧 Установка и запуск

1. Клонируйте репозиторий:

    git clone https://github.com/your-username/fshr-parser.git
    cd fshr-parser

2. Создайте и активируйте виртуальное окружение:

    python -m venv venv
    source venv/bin/activate   # Linux/Mac

3. Установите зависимости и браузер Playwright:

    pip install -r requirements.txt
    playwright install chromium

4. Отредактируйте переменную PLAYER_ID в parser.py (ID нужного шахматиста).

5. Запустите парсер:

    python parser.py

6. Результат появится в консоли и в файле ranks.csv

## 📊 Пример вывода

Найдено турниров: 24
Обрабатываю 1/24: https://ratings.ruchess.ru/tournaments/243749
  Время побед. Группа C (1450-1649) -> --
Обрабатываю 2/24: ...

...
=== РЕЗУЛЬТАТЫ ===
Время побед. Группа C | --
